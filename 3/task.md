# Описание задания

Перед выполнением задания установите **Jupyter Notebook** или используйте **Google Colab**.

Скачайте датасет [Kaggle electronic_devices_sales](https://www.kaggle.com/datasets/cameronseamons/electronic-sales-sep2023-sep2024).

## Задание 1

На основании датасета для каждого покупателя получите:

- предпочитаемый метод оплаты;
- общие траты;
- сумму денег, потраченную на дополнительные услуги и аксессуары.

## Задание 2

### 1. Рассчитайте доход

На основании датасета получите доход:

- по каждому методу доставки;
- по каждому типу продукта;
- по дополнительным услугам за каждый месяц;
- по дополнительным услугам за каждый квартал.

### 2. Постройте графики

Отобразите полученные данные на графиках.
