# Описание задания

Перед выполнением задания установите **Jupyter Notebook** или используйте **Google Colab**.

## Задание 1

Переведите содержимое файла `purchase_log.txt` в словарь `purchases` вида:

```python
{
    '1840e0b9d4': 'Продукты',
    ...
}
```

Пример работы программы при выводе первых двух элементов словаря `purchases`:

```text
1840e0b9d4 'Продукты'
4e4f90fcfb 'Электроника'
```

## Задание 2 *(необязательное)*

Для каждого `user_id` в файле `visit_log.csv` определите категорию покупки и добавьте её в третий столбец.

При этом исходный файл `visit_log.csv` изменять **не нужно**.

Запишите в файл `funnel.csv` только те визиты из файла `visit_log.csv`, в которых были покупки, с указанием категории покупки.

### Условия работы с данными

- содержимое файла `purchase_log.txt` помещается в оперативную память компьютера;
- содержимое файла `visit_log.csv` в оперативную память не помещается, поэтому необходимо использовать **построчную обработку файла**.

Пример первых трёх строк файла `funnel.csv`:

```csv
user_id,source,category
1840e0b9d4,other,Продукты
4e4f90fcfb,context,Электроника
```
